# What this tracker is

A living estimate of how many **Magnificent Monsters (MAMO)** tuck boxes Konami printed for the **Americas**, based on what we can see selling — not a press release.

Unit we count: **one tuck box**.  
Street date: **September 4, 2026**.  
Geography: **Americas only** (not Europe / Cardmarket).

---

## The three numbers (keep them separate)

| Plain name | What it means |
|---|---|
| **Proven sold (floor)** | Boxes we can point at with receipts/badges. Not a guess. |
| **Estimated sold** | Best guess of *all* Americas boxes sold so far (fills gaps we can’t see). **Main dashboard number.** |
| **Estimated print** | Sold so far + boxes still sitting in warehouses / stores / distributors. |

Do not mash those three into one multiplier.

---

## What counts

**Mass retail (first-party only)**  
Target, Walmart, Amazon.com itself, GameStop — only when *that retailer* is the seller.

**Hobby online**  
- TCGPlayer sealed box + display sold counts (display = 10 boxes).  
- Amazon **marketplace** (third-party) “bought” badges — these **do count**. At ~$35 retail / ~$42 market, flipping TCGPlayer → Amazon after fees is usually a loser, so we treat marketplace sales as real extra boxes, not automatic double-counts. We shave **3–5%** off marketplace totals for rare flipper overlap — an anomaly cushion, not a rule that “marketplace = double count.”

**Never add**  
eBay, Whatnot, Facebook, random shop sites on top of TCGPlayer; Europe; singles; inventing Walmart/GameStop numbers when they don’t show sold counts.

---

## The math (words first)

1. **TCGPlayer boxes seen** = box solds + (display solds × 10)  
2. **Amazon marketplace boxes seen** = box “bought” + (display “bought” × 10)  
3. **Proven sold** = mass first-party seen + TCGPlayer boxes seen + Amazon marketplace boxes seen  
4. **Estimated sold** =  
   - (mass first-party × **1.20** coverage for missed doors like Meijer)  
   - \+ (TCGPlayer boxes ÷ **0.25**, because TCGPlayer is ~25% of the *rest* of hobby)  
   - \+ (Amazon marketplace × **0.96**, i.e. 4% overlap cushion)  
5. **Estimated print** = estimated sold × **1.15** (about 15% still unsold in the channel in the first month)

**Important:** we do **not** divide Amazon marketplace by 0.25. That stretch is only for TCGPlayer. Marketplace is already a full observed channel.

US print ≈ Americas print × **0.88**.

---

## Sensitivity (always show a band)

- Mass coverage: 1.15 – 1.25  
- TCGPlayer hobby share: 20% – 30%  
- Marketplace overlap cushion: 3% – 5%  

---

## Weekly forecast (later)

Do **not** take week-1 sales and multiply by 4 or 12.  
Each Friday: save a new snapshot → weekly change → how fast demand is cooling → then project the tail. Needs a few Fridays before the curve is trustworthy.

---

## Grand Master Rare check (separate)

Americas lock: **1,800** serial GMRs.  
If openings log enough pulls: implied print = 1800 ÷ (GMRs found ÷ boxes opened).  
If that disagrees with sell-through by more than 2×, say which input is weak — **don’t average them**.
